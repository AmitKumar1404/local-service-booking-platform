# Local Service Booking Platform

A real-life local service booking platform built using Java, Spring Boot, PostgreSQL, and React.

The platform will allow customers to discover local service providers, view available services, and book services based on their requirements.

---

# 1. Project Overview

## What is Local Service Booking Platform?

Local Service Booking Platform is a web application that connects customers with local service providers.

Customers can search for services such as:

- Electrician
- Plumber
- Carpenter
- AC Repair
- Home Cleaning
- Appliance Repair
- Other local services

A customer can select a service, choose a service provider, and create a booking.

The platform will have three main types of users:

- Customer
- Service Provider
- Admin

---

# 2. Main User Roles

## Customer

A customer can:

- Register an account
- Login
- Browse available services
- Search for service providers
- View provider details
- Book a service
- View booking history
- Cancel a booking
- Provide feedback/review

---

## Service Provider

A service provider can:

- Register an account
- Login
- Create and manage service profile
- Add services
- Set service price
- Set availability
- View booking requests
- Accept or reject bookings
- Update booking status

---

## Admin

Admin can:

- Manage users
- Manage service providers
- Manage service categories
- View bookings
- Block/unblock users
- Monitor platform activity
